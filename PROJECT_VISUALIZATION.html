Feature Importance

Top 10 Factors for Prediction

1. Heart Rate to Blood Pressure Ratio (13.68%)

How efficiently your heart works relative to blood pressure

2. ST Depression (12.23%)

Key ECG finding indicating heart stress

3. ST Depression Transformed (11.67%)

Mathematical transformation of ST depression for better predictions

4. Thalassemia (10.63%)

Blood disorder affecting oxygen transport

5. Blood Pressure × Cholesterol (7.91%)

Combined effect of two major cardiovascular risk factors

6. ST Depression × Heart Rate (6.65%)

How heart stress changes with exercise

7. Major Vessels (5.85%)

Number of major blood vessels with significant blockage

8. Max Heart Rate (4.60%)

Highest heart rate achieved during exercise testing

9. Exercise-Induced Chest Pain (4.43%)

Whether chest pain occurs during physical activity

10. Age (4.34%)

Patient age - a basic but important risk factor

API Endpoints

15+ endpoints across V1 (stable) and V2 (advanced) versions:

V1 Endpoints (Stable)

GET / - Root endpoint GET /health - Health check POST /api/v1/predict - Manual input prediction POST /api/v1/upload-report - Upload & process report POST /api/v1/predict-from-report - Report + prediction POST /api/v1/find-doctors - Find doctors by location GET /api/v1/cardiologists - Get nearby cardiologists GET /api/v1/hospitals - Get nearby hospitals

V2 Endpoints (Advanced)

POST /api/v2/analyze-complete-report - Input: blood_report + optional (ecg_image, xray_image, angio_image) - Output: Fusion prediction + SHAP explanations + Recommendations POST /api/v2/process-cardiac-image - Input: cardiac_image + image_type (ecg/xray/angiography) - Output: Image analysis + Abnormality scores POST /api/v2/explain-prediction - Input: Patient data - Output: SHAP explanation + Clinical summary POST /api/v2/parse-report-with-llm - Input: Medical report file - Output: Structured data + Validation + Risk factors POST /api/v2/map-lab-values - Input: Lab data + patient info - Output: Model features + Risk factors POST /api/v2/complete-analysis-pipeline - Input: All available data - Output: Complete 8-component analysis
